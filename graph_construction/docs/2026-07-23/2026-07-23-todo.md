## 3. 探索路线

底层路径计算继续使用 Dijkstra

探索状态机只负责选择当前分支、确认死路和选择回退岔路

核心状态:

```text
FOLLOW_BRANCH
  -> CHECK_DEAD_END
  -> BACKTRACK
  -> CHOOSE_BRANCH
  -> FOLLOW_BRANCH

所有可达分支完成
  -> EXPLORATION_EXHAUSTED
```

### 代码修改

- [x] 增加 `ExplorationState`
- [x] 增加 `JunctionRecord`、`BranchRecord` 和 `ExplorationMemory`
- [x] 使用岔路栈和未探索方向记录替换 DeferredBranch
- [x] 按岔路和方向扇区合并 Frontier, 不把单个 Frontier UUID 当作长期分支
- [x] 初始分支优先使用第一帧健康 odom 朝向
- [x] 新分支使用岔路处的局部方向, 不再持续受初始朝向影响
- [x] `FOLLOW_BRANCH` 只允许同一方向的正常延伸
- [x] 普通延伸拒绝前进量小于 -0.5 m 的路线
- [x] 限制多次小回退累积成明显回头
- [x] `CHECK_DEAD_END` 先 hold 并等待连续有效图, 不因单帧路径消失立即回头
- [x] 只有 `BACKTRACK` 可以明显回头
- [x] `BACKTRACK` 优先选择最近记录的未探索岔路方向
- [x] 当前恢复分支失效后继续选择更早的可达分支
- [x] 输入异常只暂停状态机, 不把当前分支记为失败
- [x] graph reset 或位姿重置时清空旧图探索记忆
- [ ] 将候选生成、方向合并、状态切换和路径输出进一步拆分到独立类
- [x] 删除旧的 Deferred 和分级放宽回退逻辑

- [x] 直线探索确认死路后进入历史分支回退
